ESP-Prog

Este guia do usuário ajudará você a começar a usar o ESP-Prog e também fornecerá informações mais detalhadas.

O ESP-Prog é uma das ferramentas de desenvolvimento e depuração da Espressif, oferecendo funcionalidades como download automático de firmware, comunicação serial e depuração JTAG. As funções de download automático de firmware e comunicação serial do ESP-Prog são suportadas em todos os chips da Espressif, enquanto a depuração JTAG é suportada em todos os chips que oferecem interface JTAG.

O ESP-Prog pode ser facilmente conectado a um PC usando apenas um cabo USB. Em seguida, o PC pode identificar as interfaces (funções) de Programação e JTAG da placa por meio de seus números de porta.

Como a tensão de alimentação pode variar em diferentes placas de usuários, qualquer uma das interfaces do ESP-Prog pode fornecer alimentação de 5 V ou 3,3 V por meio de pinos seletores (headers), garantindo compatibilidade de energia. A alimentação no ESP-Prog pode ser alternada entre 3,3 V e 5 V, mas os sinais RX/TX e JTAG estarão sempre no nível de 3,3 V.

Primeiros Passos​

Esta seção fornece uma breve introdução sobre como realizar a configuração inicial de hardware do ESP-Prog.

Iniciar o Desenvolvimento de Aplicações​

Antes de ligar sua placa, certifique-se de que ela esteja em boas condições e sem sinais óbvios de danos.

Hardware Necessário​

  • ESP-Prog
  • Cabo USB 2.0 (Standard-A para Micro-B)
  • Computador com Windows, Linux ou macOS
  • Cabos Dupont ou cabos flat fornecidos pela Espressif para conectar a placa de desenvolvimento ao ESP-Prog
Nota sobre o Cabo USB

Certifique-se de usar um cabo USB apropriado. Alguns cabos servem apenas para carregamento e não possuem as linhas de dados necessárias para a programação das placas.

Configuração de Hardware​

  1. Conecte a placa ESP-Prog à porta USB do PC usando o cabo USB.
  2. O PC detectará duas portas do ESP-Prog, indicando que a placa foi conectada com sucesso. Caso as portas não sejam detectadas, instale o driver do chip FT2232HL no seu computador.
  3. Selecione a tensão de saída de alimentação para as interfaces de Programação/JTAG utilizando os pinos seletores PROG PWR SEL / JTAG PWR SEL.
  4. Conecte o ESP-Prog à placa de usuário ESP usando os cabos flat fornecidos pela Espressif.
  5. Inicie a programação (download) ou a depuração JTAG usando as ferramentas de software oficiais ou scripts fornecidos pela Espressif.

Conteúdo e Embalagem​

Vendas no Varejo​

Cada placa ESP-Prog vem em uma embalagem individual.

Conteúdo da Embalagem do ESP-Prog

O conteúdo inclui:

  • Placa de desenvolvimento: ESP-Prog
  • Cabos: Dois cabos flat flexíveis:
    • Um cabo para interface JTAG de 1,27 mm para conexão com conector macho shrouded box de 2×5 pinos.
    • Um cabo para interface PROG de 1,27 mm para conexão com conector macho shrouded box de 2×3 pinos.

Para compras em pequena quantidade, cada placa vem embalada individualmente em um saco antiestático ou em embalagem apropriada definida pelo revendedor. Para compras no varejo, acesse: Comprar uma amostra.

Vendas no Atacado​

Para pedidos em grande quantidade (atacado), as placas são enviadas em caixas de papelão maiores. Para compras em lote, acesse: Contato de Vendas.

Documentação de Referência​

Modo de Funcionamento da Ponte USB​

O ESP-Prog utiliza o chip FT2232HL, fornecido pela FTDI, como seu controlador de ponte USB. A placa pode ser configurada para converter a interface USB 2.0 em interfaces seriais e paralelas que suportam uma ampla variedade de padrões da indústria. O ESP-Prog utiliza o modo padrão de interface serial assíncrona dupla do FT2232HL, disponível após a instalação do driver do chip FT2232HL no computador.

Identificação das Portas

O PC consegue identificar as duas portas do ESP-Prog pelos seus números de porta. O número de porta maior representa a interface de Programação, enquanto o menor representa a interface JTAG.

Interface de Comunicação​

O ESP-Prog pode se conectar às placas de usuário com ESP32 utilizando tanto a interface de Programação quanto a interface JTAG.

  • Interface de Programação
    A interface de Programação possui seis pinos, incluindo a interface UART (ESP_TXD, ESP_RXD), o pino de seleção de modo de inicialização (ESP_IO0) e o pino de reset (ESP_EN). O projeto para a interface de Programação na placa do usuário deve seguir a referência fornecida na figura abaixo.

  • Design à Prova de Erros (Fool-proof)
    A placa ESP-Prog utiliza conectores de barra/box header (DC3-6P/DC3-10P) que suportam proteção contra corrente reversa no circuito. Nesses casos, recomenda-se que os usuários também utilizem conectores do tipo header em suas placas de usuário, como FTSH-105-01-S-DV-* ou DC3-*P.
Orientação dos Cabos

O encaixe dos plugues e soquetes exige uma orientação específica, o que significa que cada soquete do ESP-Prog corresponde exatamente aos plugues do cabo. O uso de um cabo incompatível pode levar a uma ordem incorreta de conexão. Por favor, utilize os cabos fornecidos pela Espressif.

Função de Download Automático​

O ESP-Prog suporta download automático de firmware. Após conectar a interface de Programação do ESP-Prog à placa do usuário, o programa de gravação pode transferir dados ou executar aplicações automaticamente controlando os estados do pino de seleção de boot (ESP_IO0) e do pino de reset (ESP_EN). Isso evita que o usuário precise reiniciar manualmente o dispositivo e selecionar os modos de download.

Os dois botões na placa ESP-Prog permitem aos usuários reiniciar e controlar o modo de inicialização (boot) do dispositivo de forma manual.

Circuito de Atraso (Delay Circuit)​

O circuito de atraso do ESP-Prog inclui buffer de barramento, inversor, MOSFET, circuito RC de primeira ordem e outros componentes. Este circuito garante que o chip ESP32 possa ser alimentado ou reiniciado antes de se conectar ao sinal JTAG, protegendo o chip contra interferências do JTAG durante a inicialização ou reset.

Indicação de Status por LED​

  • O LED vermelho acende quando o sistema está conectado à fonte de alimentação de 3,3 V.
  • O LED verde acende quando o ESP-Prog está enviando/gravando dados no ESP32.
  • O LED azul acende quando o ESP-Prog está recebendo dados do ESP32.

Pinos Seletores (Pin Headers)​

Os usuários podem selecionar a fonte de alimentação para as interfaces de Programação e JTAG através do Pino Seletor de Alimentação, além de selecionar os modos de inicialização do ESP8266 e ESP32 através do Pino IO0 On/Off.

  • Pino Seletor de Alimentação (Power Supply Select)
    O pino central é o pino de entrada de energia para cada interface. Quando conectado a 5 V, a saída de energia da interface correspondente será de 5 V. Quando conectado a 3,3 V, a saída de energia será de 3,3 V.

  • Pino IO0 On/Off
    O pino IO0 é utilizado para selecionar os modos de inicialização do ESP8266 e do ESP32. Este pino pode ser usado como um GPIO comum após o chip ser energizado. Ao remover o jumper do pino header, o usuário pode desconectar o pino IO0 manualmente para evitar que o circuito de download automático do ESP-Prog interfira no funcionamento da placa do usuário.

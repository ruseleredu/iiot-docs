# ESP-Prog-2

Este guia do usuário ajuda você a começar a usar o ESP-Prog-2 e fornece uma introdução detalhada às suas funcionalidades e recursos.

O **ESP-Prog-2** é uma ferramenta de desenvolvimento e depuração lançada pela Espressif. Ele suporta funções como download automático de firmware, comunicação serial e depuração online via JTAG. O download automático e a comunicação serial são suportados em todos os chips da Espressif, enquanto a depuração online JTAG é suportada em todos os chips que possuem interface JTAG.

O ESP-Prog-2 possui um design simples e fácil de usar: apenas um cabo USB é necessário para conectá-lo ao computador. O computador reconhece automaticamente duas portas (uma para download e outra para depuração JTAG) com base nos números das portas.

Considerando que diferentes placas de destino podem operar em tensões distintas, ambas as interfaces do ESP-Prog-2 suportam tensões de alimentação de 5 V ou 3,3 V. A tensão pode ser selecionada por meio de pinos seletores (jumpers), garantindo compatibilidade com uma variedade de placas. No entanto, embora a fonte de alimentação possa alternar entre 3,3 V e 5 V, os níveis de sinal de RX/TX e JTAG são fixos em 3,3 V.

### Iniciar o Desenvolvimento de Aplicações

Antes de ligar, certifique-se de que a placa esteja em boas condições.

#### Hardware Necessário

- **ESP-Prog-2**
- Cabo adaptador USB-A para USB-C
- Computador (Windows, Linux ou macOS)
- Cabos Dupont ou cabo flat fornecido pela Espressif para conectar a placa de desenvolvimento ao ESP-Prog-2

:::note[Nota sobre o Cabo USB]
Certifique-se de usar um cabo USB apropriado. Alguns cabos servem apenas para carregamento e não suportam transmissão de dados ou programação.
:::

#### Configuração do Hardware

1. Conecte a placa ESP-Prog-2 à porta USB do PC usando um cabo USB.
2. Use os pinos seletores PROG PWR SEL ou JTAG PWR SEL para escolher a tensão de saída da alimentação para a interface de Programação ou JTAG.
3. Utilize o cabo flat fornecido pela Espressif para conectar a placa de depuração ESP-Prog-2 à placa de destino Espressif.
4. Utilize as ferramentas de software ou scripts oficiais da Espressif para habilitar as funções de download automático e depuração JTAG.

#### Instalação do Firmware

Antes de iniciar o desenvolvimento de software, é recomendável atualizar o firmware de fábrica integrado do ESP-Prog-2. Isso garante que o dispositivo execute os recursos e correções de bugs mais recentes.

1. **Atualizar o firmware usando a ferramenta online**: Atualize o firmware do ESP-Prog-2 via ferramenta de gravação online da Espressif, o [ESP Launchpad](https://espressif.github.io/esp-launchpad/?flashConfigURL=https://espressif.github.io/esp-usb-bridge/launchpad.toml), seguindo os passos abaixo:
   - Use um navegador baseado em Chromium, como o Google Chrome.
   - **Mantenha pressionado** o botão BOOT mais próximo do módulo e conecte o cabo USB para colocar o ESP-Prog-2 no modo de download de firmware.
   - Abra a página do [ESP Launchpad](https://espressif.github.io/esp-launchpad/?flashConfigURL=https://espressif.github.io/esp-usb-bridge/launchpad.toml) no seu navegador e siga as instruções na tela para conectar e gravar o firmware.
2. **Obter o código-fonte do firmware**: Para entender a implementação do firmware, confira o código-fonte no repositório [esp-usb-bridge](https://github.com/espressif/esp-usb-bridge).

#### Configuração de Software

Para configurar o ambiente de desenvolvimento, consulte a seção [Instalação](https://docs.espressif.com/projects/esp-idf/zh_CN/latest/esp32/get-started/index.html#get-started-step-by-step) no guia [Get Started with ESP-IDF](https://idf.espressif.com/index.html).

## Documentação de Referência: Introdução às Funções

### Modo de Funcionamento da Ponte USB

O ESP-Prog-2 estabelece uma ponte entre o computador e o chip de destino baseado no ESP32-S3. Ele pode emular um dispositivo USB composto para permitir a transmissão de dados seriais através da ponte USB-para-UART, ou permitir a comunicação bidirecional JTAG por meio da ponte JTAG.

### Interface de Comunicação

- **Interface de Programação**

![Interface de Programação](/esp-prog/program_pin.png)
_Interface de Programação_

- **Interface JTAG**  
  O projeto para a interface JTAG na placa do usuário deve seguir a referência fornecida na figura abaixo.

![Interface JTAG](/esp-prog/JTAG_pin.png)
_Interface JTAG_

- **Design à Prova de Erros (Fool-proof)**  
  As interfaces do ESP-Prog-2 utilizam conectores de barra/box header (DC3-6P/DC3-10P) com proteção contra polaridade reversa. Recomenda-se o uso de conectores do mesmo tipo na placa do usuário, como `FTSH-105-01-S-DV-*` ou `DC3-*P`.

:::warning[Orientação dos Cabos]
Como os cabos flat possuem uma orientação fixa, cada interface do ESP-Prog-2 corresponde a uma conexão de cabo específica. O uso de cabos incompatíveis pode resultar em fiação incorreta. Por isso, utilize os cabos flat oficiais.
:::

### Indicação de Status por LED

- Quando a fonte de alimentação de 3,3 V do sistema estiver ligada, o **LED vermelho** acende.
- Quando o ESP-Prog-2 está realizando ponte via USB-para-UART, o **LED verde** acende.
- Quando o ESP-Prog-2 está realizando ponte via JTAG, o **LED azul** acende.

### Pinos Seletores (Pin Headers)

- **Pino Seletor de Alimentação (Power Supply Select)**  
  Os pinos identificados são os pinos de entrada de energia para cada interface. Quando conectado a **5 V**, a saída de energia da interface é de 5 V; quando conectado a **3,3 V**, a saída é de 3,3 V.

- **Pino BOOT On/Off**  
  O pino de seleção de modo de inicialização (_boot_) pode ser usado como um GPIO normal após a energização do chip. Para evitar que o ESP-Prog-2 afete o uso normal do pino BOOT na sua placa, você pode controlar manualmente o sinal do BOOT.

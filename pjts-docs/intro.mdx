## Projeto final {/* #projeto-final */}

O Projeto final tem os seguintes critérios de avaliação (Percentagem da nota):

1. Conter um dispositivo de entrada e saída (Teclado, botão, sensor, OLED...) (10%);
2. Utilizar um periférico dedicado ou rotina de interrupção (ADC, PWM, Timer...) (10%);
3. Utilizar algum protocolo de comunicação (MQTT, OPCUA, ModBus...) (10%);
4. Utilizar SQL via SQLite (5%);
5. Simulação via Wokwi (5%);
6. Ser feito em bancada, protótipo operacional (30%);
7. Dashboard via Node-RED ou FUXA (15%);
8. Documentação no GitHub (5%);
9. Video de apresentação (10%);

**Data limite de entrega: 17/12/2026**

A partir dos requisitos a equipe tem liberdade para usar tantos componentes e técnicas quanto achar necessário.

Documente o projeto em um repositório no GitHub e elabore um video breve de apresentação;

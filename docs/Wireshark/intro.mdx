## Wireshark {/* #wireshark */}

[Wireshark](https://www.wireshark.org/) is a network protocol analyzer that captures and displays network traffic in real-time. It allows users to inspect the details of network packets and analyze network performance.

### Features {/* #features */}

- Real-time packet capture and display
- Support for a wide range of network protocols
- Detailed packet analysis and filtering options
- Export capabilities for saving and sharing captured data

## Scapy: the Python-based interactive packet manipulation program & library.

[Scapy](https://scapy.net/) is a powerful Python-based interactive packet manipulation program and library. It allows users to create, send, receive, and analyze network packets with ease.

# Solicitar inclusão em um time

Esta página explica como pedir para ser adicionado(a) ao seu **grupo (time)** na
organização **`ELT85B-N21-2026-2`** do [GitHub](https://github.com/).

Toda solicitação é feita abrindo uma **issue** em um repositório dedicado, por meio
de um formulário. Depois de enviada, um administrador adiciona você ao time e fecha
a issue.

:::info[Pré-requisitos]

- Ter uma conta no [GitHub](https://github.com/).
- Saber o **slug do seu grupo** (de `grupo-a` até `grupo-j`).
- Conhecer o seu **username** do GitHub (o nome que aparece no seu perfil, sem o `@`).
  :::

## Passo a passo

### 1. Abra o formulário de solicitação

Acesse o repositório de solicitações e clique em [New issue](https://github.com/ELT85B-N21-2026-2/central/issues/new/choose) (Nova issue), ou use
o [link direto](https://github.com/ELT85B-N21-2026-2/central/issues/new?template=solicitar-time.yml):

```
https://github.com/ELT85B-N21-2026-2/central/issues/new?template=solicitar-time.yml
```

### 2. Selecione o formulário

Na tela de escolha, selecione **"Solicitar inclusão em time"**.

### 3. Preencha os campos

| Campo                      | O que informar                                          |
| -------------------------- | ------------------------------------------------------- |
| **Grupo (slug do time)**   | Escolha o slug do seu grupo, de `grupo-a` a `grupo-p`.  |
| **Seu username do GitHub** | Seu nome de usuário, **sem o `@`**. Ex.: `octocat`.     |
| **Confirmação**            | Marque a caixa confirmando que o username está correto. |

:::caution[Confira o username]
Um username digitado errado impede a inclusão e atrasa o processo. Confirme no seu
perfil antes de enviar.
:::

### 4. Envie e aguarde

Clique em **Submit new issue**. Pronto — agora é só aguardar. Um administrador irá:

1. Verificar o grupo e o username informados.
2. Adicionar você ao time correspondente.
3. Fechar a issue confirmando a inclusão.

:::tip[Como saber que deu certo]
Quando a issue for **fechada**, você já deve constar como membro do time. Você também
recebe uma notificação por e-mail convidando para a organização/time — aceite-a se
solicitado.
:::

## Como confirmar que você está no time

Acesse a página de membros do seu grupo, trocando `<slug>` pelo seu grupo:

```
https://github.com/orgs/ELT85B-N21-2026-2/teams/<slug>/members
```

Por exemplo, para o `grupo-a`:

```
https://github.com/orgs/ELT85B-N21-2026-2/teams/grupo-a/members
```

## Dúvidas frequentes

**Errei o username / escolhi o grupo errado. E agora?**
Comente na própria issue com a correção antes de ela ser fechada. Se já tiver sido
fechada, abra uma nova solicitação.

**Não sei qual é o slug do meu grupo.**
Os grupos dos alunos seguem o padrão `grupo-a`, `grupo-b`, … até `grupo-o`
(o `grupo-p` é reservado ao professor). Confirme com o professor ou com o seu grupo qual é o seu.

**Posso pedir para mais de uma pessoa na mesma issue?**
Não. Cada aluno abre a sua própria solicitação, para facilitar o controle.

:::danger[Não é o canal para dúvidas gerais]
Este repositório é **apenas** para solicitações de inclusão em times. Dúvidas sobre
conteúdo, notas ou entregas devem ser encaminhadas pelos canais oficiais da disciplina.
:::

## Pilha de Protocolos IoT: Aplicação + APS 1

**Ementa:** Camada de aplicação · MQTT · CoAP · HTTP/HTTPS · AMQP

**Stack da semana:** MQTT · CoAP · TLS · Node-RED · InfluxDB

:::note[Entrega — APS 1]
**Protótipo Sensor + Node-RED:** ESP32 no Wokwi enviando dados de temperatura/umidade via MQTT; fluxo Node-RED exibindo dashboard ao vivo com histórico.
:::

| 21   | AT   | Protocolos de aplicação IoT: MQTT vs CoAP vs AMQP vs HTTP   | Overhead, modelo request/response vs. pub/sub, casos de uso industriais de cada um                     |

# Servidor central do LAB — Node-RED + MQTT + SQLite (Docker)

### 📘 Contexto do Projeto

O script **gen_portal.py** foi projetado para automatizar a criação de um **laboratório local de IoT** voltado para ensino, integrando [Node-RED](https://nodered.org/), [nginx](https://nginx.org/) e [Mosquitto](https://mosquitto.org/) em um ambiente Docker. Ele gera todos os arquivos necessários para que uma turma de alunos possa trabalhar de forma organizada, segura e centralizada.

#### 🎯 Objetivo

- Prover um ambiente prático de IoT para turmas, com isolamento por grupo.
- Facilitar o acesso via portal web único.
- Garantir autenticação e persistência de dados.
- Automatizar a configuração completa com apenas um comando.

#### 🏗️ Componentes Gerados

- **docker-compose.yml** → Orquestra containers de nginx, Mosquitto e Node-RED (um por grupo, professor e avaliador de notas).
- **nginx.conf** → Configura o portal e os proxies reversos para cada editor Node-RED.
- **index.html** → Página inicial com cards para cada grupo, professor e painel de notas.
- **settings.js** → Configurações de autenticação e rotas para cada serviço.
- **credenciais.txt** → Arquivo com usuários e senhas gerados automaticamente.
- **Dockerfile** → Baseado em `nodered/node-red:latest`, instala módulos adicionais (SQLite, dashboards, bcrypt, FSM, SerialPort, UI Table).
- **mosquitto.conf** → Configuração do broker MQTT (porta 1883, conexões anônimas, persistência e logs).
- Estrutura de diretórios `data/<grupo>` e `settings/<grupo>.js` para cada serviço.

#### 👥 Organização

- Cada grupo é identificado por `turma-letra` (ex.: `n21-a`, `n21-b`).
- Letras reservadas:
  - **p** → professor
  - **n** → painel de notas
- Cada serviço possui dois perfis:
  - **Admin** → controle total
  - **View** → apenas leitura

#### 📌 Benefícios

- **Isolamento**: cada grupo tem seu ambiente independente.
- **Centralização**: acesso único via portal nginx.
- **Segurança**: credenciais únicas e senhas criptografadas.
- **Escalabilidade**: basta ajustar o número de grupos para expandir.
- **Automação**: todos os arquivos são gerados automaticamente pelo script.

Em resumo, o projeto entrega um **framework completo para laboratórios de ensino em IoT**, pronto para uso em sala de aula ou workshops, com acesso simplificado e gestão eficiente.

### **Comandos Úteis de Operação**

- **Gerar infraestrutura (exemplo com 2 turmas e 10 grupos cada):**

```bash
python3 gen_portal.py --turma n21 --grupos 10
```

- **Subir o ambiente:**

```bash
docker compose up -d --build
```

- **Desabilitar/Habilitar um grupo pontualmente:**

```bash
docker compose stop n21-a-nodered   # Desabilita
docker compose start n21-a-nodered  # Habilita
```

- **Aplicar alterações com remoção de turmas/grupos antigos:**

```bash
docker compose up -d --remove-orphans
```

"""Gera o LAB local com portal nginx na frente dos Node-RED.

Reservas de letras:
  - 'p' para o PROFESSOR  (ex.: n21-p)
  - 'n' para NOTAS        (ex.: n21-n)

Gera:
  - docker-compose.yml       (nginx + Node-RED por grupo + prof + avaliador de notas)
  - nginx/nginx.conf         (portal em / + proxy reverso)
  - nginx/html/index.html    (pagina inicial listando os grupos e o painel de notas)
  - settings/<grupo>.js      (configurações de autenticação e rotas)
  - data/<grupo>/            (pasta bind-montada; guarda flows.json)

Uso:
  python3 gen_portal.py       # turma n21, 10 grupos + prof + notas
  python3 gen_portal.py --turma n21 --grupos 10
"""
import sys, os, secrets, string, argparse, json
import bcrypt

ap = argparse.ArgumentParser()
ap.add_argument("--turma", default="n21", help="Identificador da turma (ex.: n21)")
ap.add_argument("--grupos", type=int, default=10, help="Quantidade de grupos de alunos")
args = ap.parse_args()

TURMA = args.turma
N = args.grupos

# Letras reservadas
LETRA_PROF = "p"
LETRA_NOTAS = "n"

# Monta alfabeto de alunos pulando 'p' e 'n'
reservadas = {LETRA_PROF, LETRA_NOTAS}
letras = [c for c in string.ascii_lowercase if c not in reservadas]

if N > len(letras):
    sys.exit(f"Máximo de {len(letras)} grupos (letras a-z sem 'p' e 'n').")

# Definição dos nomes dos serviços
grupos_alunos = [f"{TURMA}-{letras[i]}" for i in range(N)]
prof = f"{TURMA}-{LETRA_PROF}"
notas_service = f"{TURMA}-{LETRA_NOTAS}"

todos_servicos = grupos_alunos + [prof, notas_service]


def is_prof(g):
    return g == prof


def is_notas(g):
    return g == notas_service


def letra_de(g):
    if is_notas(g):
        return "n"
    if is_prof(g):
        return "p"
    return g.rsplit("-", 1)[-1]


def gerar_senha(tamanho=8):
    caracteres = string.ascii_letters + string.digits
    return ''.join(secrets.choice(caracteres) for _ in range(tamanho))


# Pré-cria diretórios e .gitkeep
for g in todos_servicos:
    os.makedirs(f"data/{g}", exist_ok=True)
    open(f"data/{g}/.gitkeep", "a").close()

credenciais_geradas = []

    hash_view = bcrypt.hashpw(senha_view.encode('utf-8'), bcrypt.gensalt(8)).decode('utf-8')

        tpl.format(
            g=g,
            cred=secrets.token_hex(16),
            titulo=titulo,
            hash_admin=hash_admin,
            hash_view=hash_view
        )

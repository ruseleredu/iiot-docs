# ESP32-DevKitC V4

Este guia mostra como começar a usar a placa de desenvolvimento ESP32-DevKitC V4.

## O Que Você Precisa

- Placa [ESP32-DevKitC V4](#visão-geral-funcional)
- Cabo USB 2.0 (Standard-A para Micro-B)
- Computador com Windows, Linux ou macOS

Você pode pular as seções de introdução e ir diretamente para a seção [Iniciar o Desenvolvimento de Aplicações](#iniciar-o-desenvolvimento-de-aplicações).

---

## Visão Geral

O ESP32-DevKitC V4 é uma placa de desenvolvimento de tamanho reduzido baseada no ESP32, produzida pela [Espressif](https://espressif.com). A maioria dos pinos de I/O está exposta nos barramentos de pinos em ambos os lados para facilitar a interconexão. Os desenvolvedores podem conectar periféricos com cabos jumper ou montar o ESP32-DevKitC V4 diretamente em uma protoboard.

Para atender a uma ampla gama de requisitos dos usuários, as seguintes versões do ESP32-DevKitC V4 estão disponíveis:

- **Diferentes módulos ESP32:**
  - [ESP32-WROOM-32E](https://www.espressif.com/sites/default/files/documentation/esp32-wroom-32e_esp32-wroom-32ue_datasheet_en.pdf)
  - [ESP32-WROOM-32UE](https://www.espressif.com/sites/default/files/documentation/esp32-wroom-32e_esp32-wroom-32ue_datasheet_en.pdf)
  - [ESP32-WROVER-E](https://www.espressif.com/sites/default/files/documentation/esp32-wrover-e_esp32-wrover-ie_datasheet_en.pdf)
  - [ESP32-WROVER-IE](https://www.espressif.com/sites/default/files/documentation/esp32-wrover-e_esp32-wrover-ie_datasheet_en.pdf)
  - [ESP32-WROOM-32D](https://www.espressif.com/sites/default/files/documentation/esp32-wroom-32d_esp32-wroom-32u_datasheet_en.pdf)
  - [ESP32-WROOM-32U](https://www.espressif.com/sites/default/files/documentation/esp32-wroom-32d_esp32-wroom-32u_datasheet_en.pdf)
  - [ESP32-WROOM-DA](https://www.espressif.com/sites/default/files/documentation/esp32-wroom-da_datasheet_en.pdf) _(Descontinuado / End of Life)_
  - [ESP32-SOLO-1](https://www.espressif.com/sites/default/files/documentation/esp32-solo-1_datasheet_en.pdf)
  - [ESP32-WROOM-32](https://espressif.com/sites/default/files/documentation/esp32-wroom-32_datasheet_en.pdf)
- **Conectores de pinos macho ou fêmea**

Para obter mais detalhes, consulte o [ESP Product Selector](https://products.espressif.com/#/product-selector?names=).

## Visão Geral Funcional

A figura a seguir e a tabela abaixo descrevem os principais componentes, interfaces e controles da placa ESP32-DevKitC V4.

![ESP32-DevKitC V4 com módulo ESP32-WROOM-32E soldado](/esp32-devkitc/esp32-devkitc-v4-functional-overview.png)
_Figura 1: ESP32-DevKitC V4 com módulo ESP32-WROOM-32E soldado_

Os principais componentes da placa são descritos a seguir, começando pelo LED indicador de alimentação de 5V, no sentido horário:

|  Nº   | Componente Chave             | Descrição                                                                                                                                                                                                           |
| :---: | :--------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **1** | LED Ligado 5V (Power On LED) | Acende quando a placa está conectada à USB ou a uma fonte de alimentação externa de 5V. Para detalhes, veja os esquemáticos em [Documentos Relacionados](#documentos-relacionados).                                 |
| **2** | Conector de I/O              | A maioria dos pinos do módulo ESP está acessível nos barramentos da placa. Você pode programar o ESP32 para habilitar múltiplas funções, como PWM, ADC, DAC, I2C, I2S, SPI, etc.                                    |
| **3** | ESP32-WROOM-32E              | Módulo com o chip ESP32 em seu núcleo. Para mais informações, veja o [Datasheet do ESP32-WROOM-32E](https://www.espressif.com/sites/default/files/documentation/esp32-wroom-32e_esp32-wroom-32ue_datasheet_en.pdf). |
| **4** | Ponte USB-para-UART          | Chip único de conversão USB-para-UART, fornecendo taxas de transferência de até 3 Mbps.                                                                                                                             |
| **5** | Botão Boot                   | Botão de download. Manter o **Boot** pressionado e em seguida pressionar **EN** inicia o modo de Download de Firmware via porta serial.                                                                             |
| **6** | Porta USB-para-UART          | Porta Micro-USB usada para alimentação da placa, bem como para comunicação entre o computador e o módulo ESP32-WROOM-32E.                                                                                           |
| **7** | Botão EN                     | Botão de reinicialização (Reset).                                                                                                                                                                                   |

## Opções de Alimentação

Existem três formas mutuamente exclusivas de fornecer energia para a placa:

1. **Porta Micro USB** (alimentação padrão)
2. **Pinos 5V e GND**
3. **Pinos 3V3 e GND**

:::warning
A alimentação deve ser fornecida utilizando **apenas uma das opções acima**, caso contrário a placa e/ou a fonte de alimentação podem ser danificadas.
:::

| **13** | IO4  |         I/O         | GPIO4, ADC2_CH0, TOUCH_CH0        |
| **14** | IO0  |         I/O         | GPIO0, ADC2_CH1, TOUCH_CH1, Boot  |
| **15** | IO2  |         I/O         | GPIO2, ADC2_CH2, TOUCH_CH2        |
| **16** | IO15 |         I/O         | GPIO15, ADC2_CH3, TOUCH_CH3, MTDO |
| **17** |  D1  |         I/O         | GPIO8, D1 <sup>[2]</sup>          |

| **19** | CLK  |         I/O         | GPIO6, CLK <sup>[2]</sup>         |

:::note[Notas de Rodapé dos Pinos]

1. **P**: Alimentação (_Power_); **I**: Entrada (_Input_); **O**: Saída (_Output_); **G**: Terra (_Ground_).
2. Os pinos **D0, D1, D2, D3, CMD** e **CLK** são usados internamente para comunicação entre o ESP32 e a memória flash SPI. Eles estão agrupados em ambos os lados perto do conector USB. Evite usar esses pinos, pois isso pode interromper o acesso à memória flash SPI / SPI RAM.
3. Os pinos **GPIO16** e **GPIO17** estão disponíveis para uso apenas em placas com os módulos ESP32-WROOM e ESP32-SOLO-1. Nas placas com módulos ESP32-WROVER, esses pinos são reservados para uso interno.
   :::

## Nota sobre o C15

O componente **C15** pode causar os seguintes problemas em versões anteriores da placa ESP32-DevKitC V4:

- A placa pode inicializar diretamente no modo Download.
- Se você gerar um sinal de clock no GPIO0, o C15 pode impactar o sinal.

Caso esses problemas ocorram, remova o componente. A figura abaixo destaca a localização do C15 em amarelo.

![Localização do C15 em amarelo na placa ESP32-DevKitC V4](/esp32-devkitc/esp32-devkitc-v4-c15-location.png)

Antes de ligar o seu ESP32-DevKitC V4, certifique-se de que a placa esteja em boas condições e sem sinais óbvios de danos.

Em seguida, prossiga para o guia [ESP-IDF Get Started](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/index.html), que ajudará você a configurar rapidamente o ambiente de desenvolvimento e gravar um exemplo de aplicação na sua placa.

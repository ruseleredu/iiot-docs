# Guia de Instalação e Configuração: Docker Desktop & WSL 2

Este guia orienta o processo completo de instalação, atualização e verificação do **Docker Desktop** e do **WSL 2 (Windows Subsystem for Linux)** no Windows 11 utilizando o gerenciador de pacotes `winget`.

:::caution[Pré-requisito Fundamental]
Todos os comandos citados neste guia devem ser executados em uma janela do **Terminal do Windows**, **Prompt de Comando (CMD)** ou **PowerShell** iniciada como **Administrador** (`Win + X` > _Terminal (Administrador)_).
:::

---

## 1. Instalação do Docker Desktop via Winget

O `winget` é o gerenciador de pacotes nativo do Windows 11 que simplifica a instalação de softwares sem a necessidade de downloads manuais.

Para realizar a instalação do Docker Desktop, execute:

```powershell
winget install --id Docker.DockerDesktop -e
```

---

## 2. Habilitação e Atualização do WSL 2

O Docker Desktop no Windows 11 utiliza a arquitetura do **WSL 2** para executar containers Linux nativamente com alta performance.

### Passo 2.1: Habilitar o WSL 2

No terminal de administrador, habilite o recurso do WSL:

```bash
wsl --install
```

:::warning[Reinicialização Necessária]
Caso o recurso WSL nunca tenha sido habilitado anteriormente na máquina, **reinicie o computador** após a execução do comando acima para que o Windows aplique as alterações de virtualização.
:::

### Passo 2.2: Atualizar e Definir a Versão Padrão

Após a reinicialização (ou caso o recurso já estivesse ativo), execute os comandos para atualizar o kernel do WSL para a versão mais recente e definir a versão 2 como padrão:

```bash
wsl --update
wsl --set-default-version 2
```

### Passo 2.3: Verificar a Versão do WSL

Para garantir que o ambiente WSL está instalado e atualizado corretamente, execute:

```bash
wsl --version
```

---

## 3. Verificação da Instalação do Docker

Com o WSL 2 configurado e o aplicativo **Docker Desktop** iniciado na máquina, abra um novo terminal e execute os comandos abaixo para validar as ferramentas CLI:

<Tabs>
  <TabItem value="cli-version" label="Versões do CLI" default>

```bash
docker --version
docker compose version
```

  </TabItem>
  <TabItem value="daemon-info" label="Informações do Daemon">

```bash
docker info
```

  </TabItem>
</Tabs>

:::tip[Dica]
Se o comando `docker info` indicar um erro de comunicação com o daemon, certifique-se de que o aplicativo **Docker Desktop** foi aberto pelo menu iniciar e que seu status esteja como _"Engine Running"_.
:::

---

## 4. Teste Prático de Validação (Container Nginx)

Para validar se o ecossistema está funcionando do início ao fim (download de imagem, criação de rede e mapeamento de porta), faça um teste rápido com a imagem oficial do **Nginx**.

### Passo 4.1: Subir o Container

Execute o container em modo _detached_ (segundo plano) mapeando a porta local `8080` para a porta `80` do container:

```bash
docker run --rm -d -p 8080:80 --name teste-nginx nginx
```

### Passo 4.2: Validar Acesso Web

1. Abra o navegador de sua preferência.
2. Acesse o endereço: [http://localhost:8080](http://localhost:8080).
3. **Resultado esperado:** A página inicial padrão do Nginx (_"Welcome to nginx!"_) deve ser exibida.

### Passo 4.3: Finalizar o Teste

Para parar e remover o container automaticamente (graças à flag `--rm` utilizada):

```bash
docker stop teste-nginx
```

---

## 5. Resumo da Instalação em Lote (Script)

Caso necessite preparar múltiplas máquinas em laboratórios de informática, você pode executar o bloco de automação abaixo:

```powershell title="Script de Instalação e Teste Rápido"
# 1. Instalar Docker e habilitar WSL
winget install --id Docker.DockerDesktop -e
wsl --install

# Nota: Reiniciar a máquina aqui caso seja a primeira vez ativando o WSL.

# 2. Atualizar componentes do WSL 2
wsl --update
wsl --set-default-version 2

# 3. Teste de Sanidade do Docker
docker run --rm -d -p 8080:80 --name teste-nginx nginx
docker stop teste-nginx
```

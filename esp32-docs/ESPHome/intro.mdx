## ESPHome

ESPHome is a system for controlling ESP32 microcontrollers with a simple and user-friendly interface.

- [ESPHome Documentation](https://esphome.io/)
- [ESPHome GitHub](https://github.com/esphome/esphome)

## ESPConfig Designer

ESPConfig Designer is a graphical tool that allows you to create and configure ESPHome devices without writing code. It provides a visual interface for defining sensors, actuators, and other components.

- https://github.com/sokolsok/ESPConfig-Designer
- https://youtu.be/CrP15p8e_z8

# Servidor central do LAB — Node-RED + MQTT + SQLite (Docker)

### 📘 Contexto do Projeto

O script **gen_portal.py** foi projetado para automatizar a criação de um **laboratório local de IoT** voltado para ensino, integrando **Node-RED**, **nginx** e **Mosquitto** em um ambiente Docker. Ele gera todos os arquivos necessários para que uma turma de alunos possa trabalhar de forma organizada, segura e centralizada.

#### 🎯 Objetivo

- Prover um ambiente prático de IoT para turmas, com isolamento por grupo.
- Facilitar o acesso via portal web único.
- Garantir autenticação e persistência de dados.
- Automatizar a configuração completa com apenas um comando.

#### 🏗️ Componentes Gerados

- **docker-compose.yml** → Orquestra containers de nginx, Mosquitto e Node-RED (um por grupo, professor e avaliador de notas).
- **nginx.conf** → Configura o portal e os proxies reversos para cada editor Node-RED.
- **index.html** → Página inicial com cards para cada grupo, professor e painel de notas.
- **settings.js** → Configurações de autenticação e rotas para cada serviço.
- **credenciais.txt** → Arquivo com usuários e senhas gerados automaticamente.
- **Dockerfile** → Baseado em `nodered/node-red:latest`, instala módulos adicionais (SQLite, dashboards, bcrypt, FSM, SerialPort, UI Table).
- **mosquitto.conf** → Configuração do broker MQTT (porta 1883, conexões anônimas, persistência e logs).
- Estrutura de diretórios `data/<grupo>` e `settings/<grupo>.js` para cada serviço.

#### 👥 Organização

- Cada grupo é identificado por `turma-letra` (ex.: `n21-a`, `n21-b`).
- Letras reservadas:
  - **p** → professor
  - **n** → painel de notas
- Cada serviço possui dois perfis:
  - **Admin** → controle total
  - **View** → apenas leitura

#### 📌 Benefícios

- **Isolamento**: cada grupo tem seu ambiente independente.
- **Centralização**: acesso único via portal nginx.
- **Segurança**: credenciais únicas e senhas criptografadas.
- **Escalabilidade**: basta ajustar o número de grupos para expandir.
- **Automação**: todos os arquivos são gerados automaticamente pelo script.

Em resumo, o projeto entrega um **framework completo para laboratórios de ensino em IoT**, pronto para uso em sala de aula ou workshops, com acesso simplificado e gestão eficiente.

### **Comandos Úteis de Operação**

- **Gerar infraestrutura (exemplo com 2 turmas e 10 grupos cada):**

```bash
python3 gen_portal.py --turma n21 --grupos 10
```

- **Subir o ambiente:**

```bash
docker compose up -d --build
```

- **Desabilitar/Habilitar um grupo pontualmente:**

```bash
docker compose stop n21-a-nodered   # Desabilita
docker compose start n21-a-nodered  # Habilita
```

- **Aplicar alterações com remoção de turmas/grupos antigos:**

```bash
docker compose up -d --remove-orphans
```

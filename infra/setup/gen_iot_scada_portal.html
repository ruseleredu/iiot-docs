gen_iot_scada_portal

Help​

py gen_iot_scada_portal.py --help
usage: gen_iot_scada_portal.py [-h] [--lab LAB] [--grupos GRUPOS] [--ip IP] [--dominio DOMINIO] [--publico-url PUBLICO_URL] [--vps-host VPS_HOST] [--vps-ssh-porta VPS_SSH_PORTA] [--vps-usuario VPS_USUARIO]
                               [--vps-porta-tunel VPS_PORTA_TUNEL] [--sem-tunel] [--sem-gitea] [--gitea-repo GITEA_REPO] [--gitea-db {postgres,sqlite}] [--sem-runner] [--runner-capacidade RUNNER_CAPACIDADE]
                               [--runner-imagem RUNNER_IMAGEM] [--runner-dns IP[,IP]] [--wokwi-token WOKWI_TOKEN] [--sem-microbin] [--sem-fuxa] [--sem-ntfy] [--proteger-http] [--novas-senhas]
                               [--github-org GITHUB_ORG] [--saida SAIDA] [--kit GRUPO] [--ponte-mqtt HOST[:PORTA]] [--porta-http PORTA_HTTP] [--segredos SEGREDOS] [--mqtt-explorer-auth]
                               [--mqtt-explorer-usuario MQTT_EXPLORER_USUARIO] [--mqtt-explorer-senha MQTT_EXPLORER_SENHA] [--mqtt-explorer-porta MQTT_EXPLORER_PORTA]

Gera o LAB IoT (caminhos + túnel SSH para o VPS).

options:
  -h, --help            show this help message and exit
  --lab LAB             Nome do lab (ex.: lab05); prefixo de tudo
  --grupos GRUPOS       Quantidade de grupos de alunos (máx. 24)
  --ip IP               IP do servidor na rede do laboratório (acesso local, MQTT e MQTT Explorer)
  --dominio DOMINIO     Domínio interno, usado só nos e-mails das contas (ex.: lab05-a@iot.lab)
  --publico-url PUBLICO_URL
                        URL pública (HTTPS) servida pelo Apache do VPS
  --vps-host VPS_HOST   Host/IP do VPS para o SSH (padrão: o host da --publico-url)
  --vps-ssh-porta VPS_SSH_PORTA
                        Porta SSH do VPS
  --vps-usuario VPS_USUARIO
                        Usuário restrito do túnel no VPS
  --vps-porta-tunel VPS_PORTA_TUNEL
                        Porta (só em 127.0.0.1 do VPS) onde o túnel entrega o portal ao Apache
  --sem-tunel           Não inclui o túnel (só rede local, http://IP/)
  --sem-gitea           Não inclui o Gitea
  --gitea-repo GITEA_REPO
                        Repositório inicial criado em cada organização ('' = nenhum)
  --gitea-db {postgres,sqlite}
                        Banco do Gitea: postgres (padrão, compartilhado) ou sqlite
  --sem-runner          Não inclui o runner do Gitea Actions (e desliga o Actions no Gitea)
  --runner-capacidade RUNNER_CAPACIDADE
                        Jobs simultâneos no runner do lab (padrão 2; cada job de ESP32 usa ~1 CPU e 2 GB)
  --runner-imagem RUNNER_IMAGEM
                        Imagem do runner (Docker-in-Docker; padrão docker.io/gitea/runner:3-dind)
  --runner-dns IP[,IP]  DNS para os containers dos jobs (padrão: o do Docker, 8.8.8.8; use o da instituição se o 53 externo for bloqueado)
  --wokwi-token WOKWI_TOKEN
                        Token do Wokwi CI do professor: vira o secret WOKWI_CLI_TOKEN de cada organização (guardado em .segredos.json; '-' remove)
  --sem-microbin        Não inclui o MicroBin (/bin/)
  --sem-fuxa            Não inclui o FUXA (SCADA/HMI por grupo em /fuxa/<grupo>/)
  --sem-ntfy            Não inclui o ntfy (notificações push por grupo em /ntfy/ e /avisos/)
  --proteger-http       Exige login (usuário/senha do grupo) nos dashboards e endpoints HTTP do Node-RED
  --novas-senhas        Sorteia senhas novas para todos os grupos (padrão: mantém as já geradas)
  --github-org GITHUB_ORG
                        Organização do GitHub com os repositórios <lab>-grupo-<letra> (para publicar os acessos)
  --saida SAIDA         Pasta de saída (padrão: <lab>; com --kit: <lab>-kits/<grupo>; com --kit todos: pasta base)
  --kit GRUPO           Gera o kit de UM grupo para a máquina do aluno (ex.: a ou lab05-a; 'todos' = um por grupo)
  --ponte-mqtt HOST[:PORTA]
                        Kit: liga (bridge) o broker do kit ao broker do lab, só com os tópicos do grupo
  --porta-http PORTA_HTTP
                        Kit: porta do portal na máquina do aluno (padrão 80; use 8080 se a 80 estiver ocupada)
  --segredos SEGREDOS   Kit: .segredos.json do lab para reaproveitar as senhas (padrão: <lab>/.segredos.json)
  --mqtt-explorer-auth  Exige login no MQTT Explorer
  --mqtt-explorer-usuario MQTT_EXPLORER_USUARIO
                        Usuário do MQTT Explorer
  --mqtt-explorer-senha MQTT_EXPLORER_SENHA
                        Senha do MQTT Explorer (gerada se omitida)
  --mqtt-explorer-porta MQTT_EXPLORER_PORTA
                        Porta do MQTT Explorer

Deploy​

LAB 04​

py gen_iot_scada_portal.py --lab lab04 --grupos 13 --ip 192.168.0.102 --sem-gitea --sem-microbin --sem-fuxa --sem-ntfy
Servidor do laboratório (uso do professor)

Um único ambiente para a turma: 14 grupos (lab04-a a lab04-x), professor (lab04-p) e painel de notas (lab04-n). Comandos para o Prompt de Comando (cmd), aberto na pasta onde está o gen_iot_scada_portal.py.

Configuração do lab04: LAB IoT completo, com túnel para o VPS

GROUPS fora da ordem do gerador
O gerador cria as contas a, b, c, d, e, f, g, h, i, j, k, l, m, o, mas GROUPS (sem P e N) tem a, b, c, d, e, f, g, h, i, j, k, l, m, x. Ajuste GROUPS em constants.

0. Crie os atalhos (valem só nesta janela do cmd; abriu outra, volte à pasta do gerador e rode de novo):

set "IOT_GEN=%CD%\gen_iot_scada_portal.py"
set "IOT_DIR=%CD%\lab04"
set "IOT_IP=192.168.0.10"

1. Instale a dependência do gerador (uma vez):

py -m pip install bcrypt

2. Gere o LAB IoT da turma (pasta lab04, ao lado do gerador):

py "%IOT_GEN%" --lab lab04 --grupos 14 --ip %IOT_IP% --github-org ELT85B-N21-2026-2 --saida "%IOT_DIR%"

3. Túnel para o VPS (uma vez): gere a chave, envie os arquivos e configure o Apache de iot.adrianoruseler.com:

cd /d "%IOT_DIR%" && docker compose run --rm --no-deps --build tunel chave
ssh ubuntu@iot.adrianoruseler.com mkdir -p iot-lab
scp -r vps tunel/chave/id_ed25519.pub ubuntu@iot.adrianoruseler.com:iot-lab/
ssh -t ubuntu@iot.adrianoruseler.com sudo bash iot-lab/vps/setup-vps.sh iot-lab/id_ed25519.pub

4. Suba os containers (a primeira vez demora):

cd /d "%IOT_DIR%" && docker compose up -d --build

5. Confira e veja as senhas de todos:

cd /d "%IOT_DIR%" && docker compose ps && type credenciais.txt

6. Abra o portal:

start https://iot.adrianoruseler.com/

7. Publique os acessos nos repositórios dos grupos (ELT85B-N21-2026-2/lab04-grupo-<letra>, arquivo ACESSO-LAB04.md). Precisa do Git for Windows e do gh autenticado (gh auth login). Primeiro confira, depois publique:

cd /d "%IOT_DIR%" && "%ProgramFiles%\Git\bin\bash.exe" publicar-acessos-github.sh --arquivo --dry-run
"%ProgramFiles%\Git\bin\bash.exe" publicar-acessos-github.sh --arquivo
Endereços e contas
  • Rede do laboratório: https://iot.adrianoruseler.com/
  • Gitea: <base>/git/ (Actions: runner do laboratório)
  • Avisos (ntfy): <base>/avisos/ · tópico da turma lab04-avisos
  • MicroBin: <base>/bin/
  • MQTT Explorer: http://192.168.0.10:3001/ (só na rede do laboratório)
  • MQTT: 192.168.0.10:1883 (só na rede do laboratório)

Operações com Docker

Subir de novo (depois de reiniciar o servidor ou de um down):

cd /d "%IOT_DIR%" && docker compose up -d

Parar (os dados ficam):

cd /d "%IOT_DIR%" && docker compose down

Reiniciar o Node-RED de um grupo (ex.: lab04-a):

cd /d "%IOT_DIR%" && docker compose restart lab04-a-nodered

Ver erros do Node-RED de um grupo (Ctrl+C para sair):

cd /d "%IOT_DIR%" && docker compose logs -f lab04-a-nodered

Ver o túnel para o VPS:

cd /d "%IOT_DIR%" && docker compose logs -f tunel

Ver o runner do CI:

cd /d "%IOT_DIR%" && docker compose logs -f gitea-runner

Mudou alguma opção? Gere de novo (as senhas são mantidas), recrie e reinicie Node-RED e MQTT:

py "%IOT_GEN%" --lab lab04 --grupos 14 --ip %IOT_IP% --github-org ELT85B-N21-2026-2 --saida "%IOT_DIR%" && cd /d "%IOT_DIR%" && docker compose up -d --build --remove-orphans && docker compose restart lab04-a-nodered lab04-b-nodered lab04-c-nodered lab04-d-nodered lab04-e-nodered lab04-f-nodered lab04-g-nodered lab04-h-nodered lab04-i-nodered lab04-j-nodered lab04-k-nodered lab04-l-nodered lab04-m-nodered lab04-x-nodered lab04-p-nodered lab04-n-nodered mosquitto

Refazer usuários, organizações e secrets do Gitea:

cd /d "%IOT_DIR%" && docker compose run --rm gitea-init

Token do Wokwi CI (vira o secret WOKWI_CLI_TOKEN de cada organização e fica guardado no .segredos.json):

py "%IOT_GEN%" --lab lab04 --grupos 14 --ip %IOT_IP% --github-org ELT85B-N21-2026-2 --saida "%IOT_DIR%" --wokwi-token SEU_TOKEN && cd /d "%IOT_DIR%" && docker compose up -d && docker compose run --rm gitea-init

Atualizar as imagens:

cd /d "%IOT_DIR%" && docker compose pull && docker compose build --pull && docker compose up -d

Retirar os acessos dos repositórios dos grupos (fim do semestre):

cd /d "%IOT_DIR%" && "%ProgramFiles%\Git\bin\bash.exe" publicar-acessos-github.sh --remover
Senhas novas para todos

Invalida as senhas atuais de todos os grupos: depois, publique os acessos de novo (passo 7).

py "%IOT_GEN%" --lab lab04 --grupos 14 --ip %IOT_IP% --github-org ELT85B-N21-2026-2 --saida "%IOT_DIR%" --novas-senhas && cd /d "%IOT_DIR%" && docker compose up -d --build && docker compose restart lab04-a-nodered lab04-b-nodered lab04-c-nodered lab04-d-nodered lab04-e-nodered lab04-f-nodered lab04-g-nodered lab04-h-nodered lab04-i-nodered lab04-j-nodered lab04-k-nodered lab04-l-nodered lab04-m-nodered lab04-x-nodered lab04-p-nodered lab04-n-nodered mosquitto && docker compose run --rm gitea-init
Apagar tudo

Remove containers e volumes (Gitea, PostgreSQL, ntfy, MicroBin, MQTT) de toda a turma. Os fluxos em data/ e as telas em fuxa/ ficam na pasta.

cd /d "%IOT_DIR%" && docker compose down -v
